# MazeWar.dev

Notes and references about MazeWar, with the intent of creating a network-playable version using standard user-agents.


## Schemes
### User interactions:
* In a browser with a connection over websockets.
* Over SSH using a terminal that has line drawing capability (probably won't work for most users)
